# discord-plugin

CoreBlow plugin: discord-plugin

## Installation

```bash
coreblow plugin install ./discord-plugin
```

## Configuration

Add to your `config.json`:

```json
{
  "plugins": {
    "discord-plugin": {
      "enabled": true
    }
  }
}
```

## Development

```bash
npm install
npm run dev       # Watch mode
npm test          # Run tests
npm run build     # Production build
```
