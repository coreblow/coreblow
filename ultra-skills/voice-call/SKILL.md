# Ultra Voice Call

Voice call management.

## When to Use
 "Call this number", "Start a conference call", "Transcribe call"

## Workflow
1. Select provider (Twilio/Vonage/WebRTC)
2. Initiate or answer call
3. Stream STT for real-time transcription
4. AI processes transcript and responds via TTS
