# Ultra WhatsApp CLI

WhatsApp messaging via web bridge.

## When to Use
 "Send WhatsApp message", "Check WhatsApp", "Send image on WhatsApp"

## Workflow
1. Ensure WhatsApp Web bridge is connected (scan QR once)
2. Use REST API to send/receive messages
3. Support text, images, files, and location messages
