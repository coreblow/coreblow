# Ultra Session Logs

Conversation history management.

## When to Use
 "Show conversation history", "Search past sessions", "Export this chat"

## Features
- Auto-save all conversations
- Search by keyword, date, channel
- Export as Markdown, JSON, or HTML
- Tag important conversations
- Analytics (message count, tokens used, response times)
