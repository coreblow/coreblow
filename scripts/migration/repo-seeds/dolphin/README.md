# Dolphin

CoreBlow-native typed workflow shell.

Dolphin turns CoreBlow skills, tools, and local actions into typed workflow steps. It is split from the core runtime so workflow authoring and execution can mature without coupling every automation concern to `coreblow/coreblow`.

## Scope

- Define typed workflow steps.
- Validate workflow plans before execution.
- Keep automation plans serializable and auditable.
