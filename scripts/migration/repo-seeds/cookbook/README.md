# CoreBlow Cookbook

Example apps and recipes for the CoreBlow SDK.

This repository is the public example surface for CoreBlow. Recipes stay
outside `coreblow/coreblow` so they can grow independently from runtime code.

## Recipes

- `recipes/hello-agent.md` shows the shape of a minimal CoreBlow integration.
- `examples/hello-agent` contains a runnable JavaScript example.
