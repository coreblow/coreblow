# CoreBlow Trust

CoreBlow trust and safety resources.

This repository is the public policy surface for security posture, abuse
handling, and release trust resources. It does not contain runtime code.

## Resources

- `threats.json` lists tracked threat categories and owner groups.
- `security-response.md` documents first-response expectations.
- `contributing.md` explains how to propose policy changes.
