# Openai Whisper Api

## Overview
This skill provides openai whisper api functionality for CoreBlow agents.

## Usage
Add this skill to your agent configuration:
```yaml
skills:
  - openai-whisper-api
```

## Commands
- `/openai-whisper-api` — Main command
- `/openai-whisper-api help` — Show help
