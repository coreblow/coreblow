# Openai Image Gen

## Overview
This skill provides openai image gen functionality for CoreBlow agents.

## Usage
Add this skill to your agent configuration:
```yaml
skills:
  - openai-image-gen
```

## Commands
- `/openai-image-gen` — Main command
- `/openai-image-gen help` — Show help
